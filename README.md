# Wip-Shareについて
wip-shareは作業進捗をライトに共有できることを目的としたSNSツールを想定

ユーザは「投稿者」と「閲覧者」に大きく分類される

### 投稿者
* ログイン・認証必須
* 投稿したものは外部SNSで共有可
* 進捗を1ポストに1画像投稿、それをチェインして完成を目指していく感じ

### 閲覧者
* ログインなしでも閲覧可能
* タイムライン上に流れたり、シェアされたリンクを通して閲覧可能
* 見るだけならだれでも見れるが、アクションや保存などの機能はログイン必須


# 初期リリース版(v0.0.x)
### 必要機能
* 投稿機能（新規投稿、追加投稿、画像投稿）
* タイムライン機能
* 進捗詳細閲覧機能
* 認証機能
* ユーザ情報照会・更新機能
* 共有機能
* アクション機能（いいね、スタンプ）
